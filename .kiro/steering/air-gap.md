# Air-Gap Rules

BaudVault handles passwords, seed phrases, and private keys. Its main promise is that the secret never leaves the device except as sound. Every rule below protects that promise. Do not relax a rule to make a feature easier. Raise it with the user instead.

## Forbidden in `src/`

Never write any of these identifiers in a file under `src/`, including in comments, strings, and test files:

- `fetch`
- `XMLHttpRequest`
- `WebSocket`
- `EventSource`
- `sendBeacon`
- `RTCPeerConnection`

The Air-Gap Guard hook (`.kiro/hooks/airgap-guard.json`) finds them by plain text search and fails the change. Rename a variable rather than use one of these words (for example `loadSamples`, not `fetchSamples`).

## Also forbidden

- Loading scripts, stylesheets, fonts, or images from another origin. That rules out CDNs, Google Fonts, analytics, error reporting, and remote icons. Put the asset in `public/` or import it.
- Adding a dependency that phones home or needs network access at runtime. Check before adding any package.
- Writing Plaintext, Passwords, derived keys, or decrypted bytes to `console`, `localStorage`, `sessionStorage`, IndexedDB, cookies, or the URL.
- Including secret material in error messages. Error classes in `src/core/errors.ts` take a fixed message and safe numbers only.
- Using `Math.random` or the seeded PRNG in `src/channel/prng.ts` for any security value. Salts, IVs, Shard set IDs, and Shamir coefficients come only from `crypto.getRandomValues`.

## Allowed

- Web Crypto (`crypto.subtle`, `crypto.getRandomValues`), `CompressionStream`, `DecompressionStream`.
- Web Audio, `getUserMedia` for the microphone, and loading the AudioWorklet module from the same origin.
- `Blob` and object URLs for WAV download, and `File`/`FileReader` APIs for WAV import.
- The offline service worker. It is generated by the build plugin into `dist/`, not written under `src/`, and serves only same-origin precached files.

## Tests

The Vitest setup file `test/no-network.setup.ts` replaces network APIs with stubs that throw. It sits outside `src/` because it has to name the forbidden identifiers. A test that needs the network is a design error. Generate the data locally instead.
